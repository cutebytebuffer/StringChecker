# StringChecker

StringChecker is a Rust-based program that locates the modpath of the currently running Minecraft instance and checks the strings of each mod.

## Status

StringChecker is currently in development and is not intended for use in real screenshares yet. The current version does not contain enough signatures to reliably detect most clients, modules, etc.

I'm unsure whether I'll continue updating it in the future.

## Usage

- Download the source
- Build it using the Rust compiler of your choice
- Run the executable while a Minecraft instance is open
